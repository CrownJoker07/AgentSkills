## 来源适用范围

不要用一个统一优先级混合判断不同类型的问题。先确定要证明的内容，再选择证据：

- **当前实现**：线上配置、服务端数据、当前代码和运行结果。
- **产品意图**：已批准 PRD、策划案和决策记录。
- **玩家行为**：Telemetry、Analytics、A/B Test 和 Playtest Observation。
- **玩家主观体验**：Interview、Survey 和客服/社区反馈。
- **分析框架**：S001–S012；用于组织分析和提出假设，不证明项目事实。
- **行业背景与 Benchmark**：S013–S014；用于提供背景，不作为项目目标。
- **竞品类比**：只能用于产生假设，不能单独作为结论依据。

当产品意图和当前实现冲突时，分别报告预期行为与实际行为，不用其中一方覆盖另一方。
